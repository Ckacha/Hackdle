# Hackdle
A Wordle Clone but for Hack Club Hackathons!

However, you may be asking... "How?"

And works off of the following fields:
    Name
    Date Started
    Date Ended
    Event Type(virtual/in-person)
    Project Type(hardware/software/cad/all)
    Organizer(s) 


Check it out [here](hackdle.ckacha.dev)
